# Zumbarl UI Screenshot Archive

This folder groups UI screenshots by the workflows documented in `docs/zumbarl_ai_workflows.md` and `docs/zumbarl_processes.md`.

## Workflow Folders

- `01_opportunity_gig_job/` - opportunity creation, job/gig discovery, student applications or proposals, and business applicant review.
- `02_marketing_campaign/` - campaign creation, social content workflow screens, milestones, and campaign/sales dashboards.
- `03_project_team_program/` - team workspace and project summary screens for longer-running student team programs.
- `04_learn_career_ladder/` - learning home, career hub, lessons, quizzes, notes, resources, writing support, and achievements.
- `05_connect_community/` - groups, communities, events, Explore/Connect feed, messages, profiles, and social proof.
- `06_marketplace_shop/` - marketplace discovery, product detail, offers, seller shops, cart, checkout, payment, and orders.
- `07_services_support/` - campus services, academic support, tutoring, expert help, wellness, support, and FAQs.
- `08_finance/` - budgeting and finance-related screens.
- `90_platform_shell/` - app home, dashboard, data dashboard, and product map screens that support multiple workflows.

## Page Folder Rule

Each workflow folder contains page or process subfolders, for example:

- `01_opportunity_gig_job/01_create_opportunity`
- `01_opportunity_gig_job/04_review_approve_applicants`
- `06_marketplace_shop/05_cart_checkout_payment`
- `05_connect_community/02_events`

When adding new screenshots, place them under the workflow first, then the user action or page state. If a screen supports multiple workflows, put it in the workflow where the primary user action happens, or use `90_platform_shell` for shared navigation/dashboard screens.
