Yes. Your current KYC captures identity, but not enough for the kind of ecosystem Zumbarl is becoming.

Right now you mostly have:

* personal identity
* campus identity
* documents
* skills
* business registration

That’s basic onboarding KYC.

But for Zumbarl, you actually need **4 layers of KYC**:

---

# 1. Identity KYC

(Who are you?)

You already have most of this.

## Students

You have:

* name
* email
* student email
* phone
* DOB
* gender
* campus
* course
* student ID
* government ID
* CV

You’re still missing:

### Important additions

* selfie/live face verification
* emergency contact
* expected graduation year
* hostel/location area (not exact)
* social verification (optional)
* preferred payment method
* MPesa ownership verification
* device fingerprint
* language preference

---

## Businesses

You have:

* business name
* office phone
* location
* sector
* services needed
* incorporation docs

Missing:

* KRA PIN
* business representative
* verified company email
* LinkedIn/website
* years operating
* payment method verification
* invoice/contact person
* business social presence
* office verification level

# 2. Trust KYC

(Can we trust you?)

THIS is the important one.

You need:

* repeat transaction rate
* failed jobs
* cancellation rate
* dispute count
* complaint count
* lateness score
* delivery confirmations
* peer endorsements
* SME endorsements
* verified campus communities
* group participation
* account age
* behavioral scoring

This becomes:

> Zumbarl Trust Score

Very important.

---

# 3. Financial KYC

(Can you safely participate in money systems?)

Since you’re entering:

* savings
* micro-advances
* wallets
* lending
* group funding
* escrow

You need:

### Students

* MPesa verification
* account ownership verification
* repayment behavior
* HELB status (optional)
* spending category profiling
* withdrawal limits
* transaction velocity monitoring

### Businesses

* settlement account
* invoice verification
* payment history
* payout authorization
* tax/business compliance flags

---

# 4. Operational KYC

(Can you perform specific activities?)

This is missing entirely.

Different activities need different verification.

Example:

| Activity            | Needed                          |
| ------------------- | ------------------------------- |
| Graphic design gigs | portfolio                       |
| Deliveries          | live location + trusted contact |
| Counseling          | certification                   |
| Marketplace selling | item proof                      |
| Notes selling       | plagiarism checks               |
| Campus errands      | repeat reliability              |
| Mentorship          | endorsement                     |
| Event organizing    | organizer verification          |

This is SUPER important.

---

# BIG THING YOU'RE MISSING:

# Progressive KYC

Don’t force full KYC immediately.

Students hate long onboarding.

Instead:

| Stage              | Unlock           |
| ------------------ | ---------------- |
| Phone only         | browse           |
| Student ID         | apply for gigs   |
| National ID        | receive payments |
| Face verification  | withdrawals      |
| Portfolio approved | premium gigs     |
| Endorsements       | mentorship       |
| Repeat jobs        | higher limits    |

This makes onboarding MUCH smoother.

---
